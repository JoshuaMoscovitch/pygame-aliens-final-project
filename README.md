# Pygame Aliens Final Project

This project is a modified version of the Aliens / Space Invaders example from the Pygame Examples library.

## Features Added

- Main menu system
- High score saving system using JSON
- Difficulty levels: Facile, Moyen, Difficile
- Special power-ups:
  - Shield
  - Double shot
  - Extra life
  - Slow enemies

## Requirements

To run this game, you need:

- Python 3
- Pygame

## Installation

Install Pygame using:

```bash
pip install pygame
